# Overview

This project demonstrates the development of a **Windows Forms desktop application in C#** designed to perform **numeric decomposition (factorization)**.

The application allows users to input a number and visualize its decomposition into factors, demonstrating fundamental programming concepts such as:

- event-driven programming
- desktop UI development
- object-oriented programming
- algorithm implementation

---

# Case Study

## Problem

Many mathematical operations require understanding the decomposition of numbers into their fundamental factors.

This project demonstrates how a **desktop application can interact with the user interface and execute mathematical algorithms in real time**.

---

## Solution

The application was implemented using **C# and Windows Forms**, allowing users to input a number and trigger the decomposition logic through a simple UI interaction.

The system processes the number and displays the decomposition results dynamically in the interface.

# Architecture

The application follows a simple **event-driven desktop architecture**:
```text
User Interface (Windows Forms)
│
▼
Event Handlers (Button Click)
│
▼
Number Decomposition Algorithm
│
▼
Result Rendering in UI
```

This structure demonstrates how desktop applications handle user interaction and computation.
